## Домен
Сейчас сайт на https://murzzsite.github.io/sabitova-psy/ . Когда появится домен:
1. заменить адрес `https://murzzsite.github.io/sabitova-psy/` на адрес домена во всех файлах (index.html, documents.html, privacy.html, materials.html, scripts.html, presentation.html, outreach.html, robots.txt, sitemap.xml). Подсказка в комментарии SITE_URL в head index.html;
2. добавить файл CNAME с доменом;
3. добавить сайт в Яндекс Вебмастер и Google Search Console, отправить sitemap.xml.
